# 实体词典导出说明

> 用途：从服务器数据集 `exp_4dchain_v2_dataset.pkl` 导出四维实体词典，供公开仓库 `ZGL998/My-project` 使用。
> 产物：`entity_dictionary.json`（含抽取期 182 实体 + 建模期 123 实体，按维度分组）。

---

## 一、实体词典是什么、存在哪

实体词典是论文 §3.3 超图构建的核心词汇表：

| 词典 | 数量 | 含义 | 存放位置 |
|---|---|---|---|
| 抽取期实体并集 | **182**（hist 12 / evidence 144 / treat 9 / severity 17） | 253 例患者抽取出的全部唯一实体 | `ds['entity_data']` 各维并集 |
| 建模期词汇 | **123**（hist 12 / evidence 84 / treat 9 / severity 18） | 出现 ≥2 患者的实体（论文所有实验用） | `ds['ent2id']` 的键 |

**实体格式**：`(前缀, 名称)` 二元组，前缀→维度映射：

| 前缀 | 维度 |
|---|---|
| `sym`（症状）、`diag`（诊断） | `hist`（病史） |
| `lab`（检验）、`img`（影像） | `evidence`（证据） |
| `med`（用药） | `treat`（诊疗） |
| `score`、`sev`（严重度评分/体征） | `severity`（严重度） |

> 注：`diag`（诊断）实体在建模数据集构建阶段已被移除（防「出院主诊断」标签泄漏，见 `diag_hg_event_leakage.py`），
> 因此实际导出的 `entity_dictionary.json` 中 **hist 维度只含 `sym` 实体**，不含 `diag`。

**数据文件位置**：`hg_fix_run/exp_4dchain_v2_dataset.pkl`（即运行 `exp_4dchain_v2.py --build-only` 生成的 pkl，见 `withholding_list.json` 的 `source_dataset` 字段）。

---

## 二、导出步骤

### 步骤 1：找到数据集 pkl 文件

```bash
find /你的路径 -name "exp_4dchain_v2_dataset.pkl" 2>/dev/null
```

### 步骤 2：运行导出脚本

导出脚本已随本仓库发布：[`src/paper_experiments/export_entity_dictionary.py`](../src/paper_experiments/export_entity_dictionary.py)。
在服务器上（需有 numpy/pandas 的 python 环境，本仓库实验统一用 `/home/pumc/anaconda3/bin/python3`）运行：

```bash
python export_entity_dictionary.py hg_fix_run/exp_4dchain_v2_dataset.pkl entity_dictionary.json
```

脚本逻辑：
1. `extraction_stage` —— 遍历 `ds['entity_data']` 的 253 例患者，对 `hist/evidence/treat/severity` 四维实体取并集（182）。
2. `modeling_vocab` —— 取 `ds['ent2id']` 的全部键，按前缀映射回维度（123）。

### 步骤 3：核对自检输出

运行后应打印（本次服务器实测一致）：

```
抽取期实体总数: 182 (应为 182)
建模期词汇总数: 123 (应为 123)
抽取期按维度: {'evidence': 144, 'hist': 12, 'severity': 17, 'treat': 9}
建模期按维度: {'evidence': 84, 'hist': 12, 'severity': 18, 'treat': 9}
```

## 三、产物结构（entity_dictionary.json）

```json
{
  "source_dataset": "hg_fix_run/exp_4dchain_v2_dataset.pkl",
  "extraction_stage": {
    "hist":     ["sym::咳嗽", "sym::喘憋", ...],      // 12 个
    "evidence": ["lab::CRP_high", "img::胸部CT", ...], // 144 个
    "treat":    ["med::抗生素", ...],                 // 9 个
    "severity": ["score::mmrc_4", "sev::resp_failure", ...] // 17 个
  },
  "modeling_vocab": {
    "hist":     [...],  // 12 个
    "evidence": [...],  // 84 个
    "treat":    [...],  // 9 个
    "severity": [...]   // 18 个
  },
  "counts": {
    "extraction_total": 182,
    "extraction_by_dim": {"evidence": 144, "hist": 12, "severity": 17, "treat": 9},
    "modeling_total": 123,
    "modeling_by_dim": {"evidence": 84, "hist": 12, "severity": 18, "treat": 9}
  }
}
```

> 说明：抽取期 severity（17）与建模期 severity（18）数量不同，是因为建模词表按「出现 ≥2 患者」重建，
> 两个口径下 severity 实体集合略有差异，属正常现象（与论文 §3.3 表述一致）。
