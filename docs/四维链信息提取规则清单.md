# 四维链信息提取规则与指标清单

> 生成侧（提取规则实现）位于训练集目录（`$TRAIN_ROOT`）；HyperGraphRAG 为消费侧（读取「字段分组明细 / 合并相似链条」做相似匹配）。

## 1. 规则与实现位置

| 项目 | 路径 |
|---|---|
| 提取规则（JSON） | `$TRAIN_ROOT/出院主诊断_COPD三类/四维相似链处理规则.json` |
| 提取脚本 | `$TRAIN_ROOT/build_similarity_chains.py` |
| 输出目录 | `出院主诊断_COPD三类/慢性阻塞性肺病/四维相似链输出/` |

## 2. 四维链 → 13 个字段分组映射

| 四维链（输出文件） | 字段分组（分组名 g） |
|---|---|
| 病史背景 `history_background` | 患者人口学基础信息、全维度病史信息 |
| 临床证据链 `clinical_evidence_chain` | 症状体征信息、检查检验信息、诊断信息 |
| 诊疗轨迹 `treatment_trajectory` | 药物治疗信息、手术治疗信息、诊疗过程信息、出院信息 |
| 临床严重度 `clinical_severity` | 疾病分期与严重程度、并发症信息、功能评分信息、预后信息 |

## 3. 各分组实际提取的指标

| 分组 | 提取指标（payload 字段） | 数据源 |
|---|---|---|
| 患者人口学 | 性别、年龄、入院/出院时间、入院科室、出院科室 | 基本数据、病案首页 |
| 全维度病史 | 主诉、现病史、既往史、个人史、家族史、过敏史、婚育史、首程病例特点 | 电子病历、首次病程「病例特点」 |
| 症状体征 | 主要症状(=主诉)、现病史摘要、体格检查、生命体征(体温/脉搏/呼吸/血压/血氧/SPO2) | 电子病历、护理记录最新值 |
| 检查检验 | 检验项目列表(报告日期/检验项目/指标名/指标值/单位/参考范围)；影像检查列表(时间/项目/部位/所见/结论)；肺功能相关子列表 | 实验室检查、影像学检查（含「肺功能/通气/弥散/FEV/FVC」关键词） |
| 诊断信息 | 入院/出院诊断(拆分)、主要诊断、其他诊断、ICD编码列表、病理诊断、诊断依据、首程诊断推理(病例特点/入院诊断/诊断依据/鉴别诊断) | 电子病历、病案首页、首次病程 |
| 药物治疗 | 用药医嘱列表(开始/结束时间、医嘱名称、频次、用法、剂量、单位、药物分类)、用药用法、用药疗程 | 医嘱表（含非药物医嘱过滤 + 7类药字典分类） |
| 手术治疗 | 手术列表/详情(名称/日期/级别/麻醉方式)、麻醉记录 | 手术记录、病案首页(主要/其他手术操作1-40) |
| 诊疗过程 | 治疗原则、诊疗过程描述(病程逐条事件)、全过程诊疗时序总结、治疗效果 | 病程记录、出院诊疗经过、首程诊疗计划 |
| 出院信息 | 出院日期、出院症状、出院医嘱、出院结局、离院方式、出院诊断(列表) | 病案首页、出院记录 |
| 疾病分期与严重程度 | 疾病分期(GOLD 1-4期正则)、严重程度分级(轻/中/重/极重度正则)、分期依据(FEV1/FVC/通气障碍/弥散障碍/急性加重片段≤8条) | 入院/出院诊断、出院记录、影像结论 |
| 并发症 | 并发症列表(排除主诊断及COPD本身)、数量、分级(含呼吸衰竭/心衰/脓毒/感染→重度) | 诊断信息二次加工 |
| 功能评分 | 入院/出院功能评分(同一组，评分变化=None)，正则 `(Barthel\|mMRC\|CAT\|ADL\|APACHE\|BODE\|NRS2002\|MNA\|6MWT)+数值` | 出院记录、现病史、病程记录文本 |
| 预后 | 住院天数(病案首页「实际住院（天）」，缺失用日期差)、出院结局、再入院风险、预后评估 | 病案首页 |

## 4. 关键提取规则细节

### 4.1 药物分类字典（classify_medication）
- 支气管扩张剂：沙丁胺醇、异丙托溴铵、噻托溴铵、特布他林、复方异丙托溴铵、沙美特罗、福莫特罗
- 糖皮质激素：布地奈德、甲泼尼龙、泼尼松、地塞米松、氢化可的松
- 抗生素：阿奇霉素、头孢、左氧氟沙星、莫西沙星、哌拉西林、美罗培南
- 祛痰平喘：氨溴索、乙酰半胱氨酸、茶碱、多索茶碱
- 抗纤维化：尼达尼布、吡非尼酮
- 降糖药：阿卡波糖、二甲双胍、胰岛素、达格列净
- 降压药：替米沙坦、氨氯地平、倍他乐克、缬沙坦
- 其余归为「其他」

### 4.2 严重度提取正则（extract_stage_info）
- 疾病分期：`(?:GOLD\s*|慢性阻塞性肺疾病(?:急性加重)?)([IVⅠⅡⅢⅣ1-4]+(?:级)?)`
- 严重程度分级：`(轻度|中度|重度|极重度)[^\n，。；;]{0,16}(?:阻塞性通气障碍|弥散功能障碍|慢阻肺)`（16 字内共现）
- 分期依据：`FEV1` / `FVC` / `阻塞性通气障碍` / `弥散功能障碍` / `急性加重` 片段各取前 8 条

### 4.3 功能评分正则（extract_scores）
- `(Barthel|mMRC|CAT|ADL|APACHE|BODE|NRS2002|MNA)[^\d]{0,10}(\d+(?:\.\d+)?)`
- `(6分钟步行|6MWT)[^\d]{0,10}(\d+(?:\.\d+)?)`

## 5. 输出结构（每病例/每维度）

```
病例标识（编号/性别/年龄/时间/主诊断）
字段分组明细: [{字段分组, 核心字段, 数据处理逻辑, 相似度匹配核心依据, 提取结果, 相似链条}]
合并相似链条（各分组相似链条拼接文本）
```

全程脱敏：删除姓名/地址/联系方式/住院号/身份证/病案号；删除职业/民族/婚姻/国籍/籍贯；医护姓名→角色化匿名（如「主治医师1」）。

## 6. 与审计发现相关的点

1. **H3 字段名错位**：规则与代码本意提取 `严重程度分级`/`分期依据`（`extract_severity_info`），而实验脚本 `exp_4dchain.py` 读的是 `疾病分期` → GOLD/mMRC/CAT 实体全为 0。
2. **H4 功能评分来源**：`extract_scores` 虽支持 mMRC/CAT 正则，但只从出院记录/现病史/病程文本扫描，实际只能命中 6MWT/APACHE（mMRC/CAT 无对应文本来源）。
3. **严重度分级阈值**：`extract_stage_info` 要求「轻/中/重/极重度」与「阻塞性通气障碍/弥散功能障碍/慢阻肺」在 16 字内共现，覆盖率有限。
