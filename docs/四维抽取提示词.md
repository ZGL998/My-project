# 四维信息抽取提示词（LLM）

> 论文正文（Section 2.3）所述四个维度抽取提示词的完整原文，对应手稿 Multimedia Appendix Text S1 与 `实验执行提示词.md` Step 1。
> 每个提示词输入为该患者对应文档的拼接文本，输出为严格 JSON。

## 维度 1 — 患者历史（患者历史）

**输入文档**：入院记录、病史记录

```
你是一名临床信息抽取系统。从以下入院记录和病史记录中提取患者基线信息。
仅输出合法 JSON，不要输出其他文本。

字段：
- age: 整数，患者年龄（若无可填 null）
- sex: "男" 或 "女"（若无可填 null）
- smoking_history: 对象 {
    status: "never"|"former"|"current",
    pack_years: 浮点数|null
  }
  status 依据：「否认吸烟史」→"never"；「已戒烟X年」→"former"；「吸烟X年，每日Y支」→"current"
  pack_years = (日支数×年数)/20，无数据则 null
- comorbidities: 数组，每项 {
    disease_name: "标准化疾病名称",
    onset_year: 整数|null
  }
- prior_medication: 数组，每项 {
    drug_name: "通用名",
    drug_class: "LABA"|"LAMA"|"ICS"|"SABA"|"SAMA"|"combination"|"antibiotic"|"other",
    duration_months: 整数|null
  }
- prior_exacerbation_count_12m: 整数|null

排除规则：
- 不提取家族史和鉴别诊断中的疾病
- 模板套话（如"否认高血压病史"）不视为患病
- 无信息字段填 null
```

## 维度 2 — 临床证据

**输入文档**：检验报告、肺功能报告、影像报告、护理记录

```
从以下检验报告、肺功能报告、护理记录和影像报告中提取客观临床测量数据。仅输出 JSON。

字段：
- pulmonary_function: {fev1_l, fvc_l, fev1_fvc_ratio, fev1_percent_predicted} 全为 float|null
- blood_gas: {pao2_mmHg, paco2_mmHg, ph, spo2_percent} 全为 float|null
- vital_signs: {temperature_c, heart_rate, respiratory_rate, systolic_bp, diastolic_bp} 全为 float|int|null
- inflammatory_markers: {crp_mg_L, wbc_count, neutrophil_pct, eosinophil_count, procalcitonin_ng_ml} 全为 float|null
  CRP 单位统一 mg/L（若为 mg/dL 则 ×10）
- biochemistry: {albumin_g_L, creatinine_umol_L, glucose_mmol_L} 全为 float|null
- imaging_findings: [{modality: "CT"|"X-ray"|"超声"|"MRI", finding_type, location, severity}] 仅阳性发现
- microbiology: {sputum_culture: "正常菌群"|"检出病原菌"|"未做"|null, pathogen_name: "名称"|null}

规则：取最近一次治疗前值；不保留比较符号（"FEV1<40%"→40.0）；无信息填 null
```

## 维度 3 — 治疗轨迹

**输入文档**：入院记录、病程记录、医嘱单、出院小结（按时间拼接）

```
从以下入院记录、病程记录、医嘱单和出院小结中提取治疗事件的时间序列。仅输出 JSON。按时间顺序排列。

字段：
- events: [{
    date_offset_days: 整数（入院日=day 0），
    event_type: "admission"|"medication_change"|"oxygen_therapy"|"NIV_initiation"|"ICU_admission"|"surgery"|"discharge",
    description: "≤30字简述",
    details: 对象（按 event_type 不同）：
      admission → {chief_complaint, admission_diagnosis}
      medication_change → {drug_name, drug_class, change_type: "initiation"|"discontinuation"|"dose_increase"|"dose_decrease"|"switch", dose, route, clinical_rationale}
      oxygen_therapy → {flow_rate_L_min, delivery_method: "鼻导管"|"面罩"|"高流量"}
      NIV_initiation → {mode: "BiPAP"|"CPAP", settings}
      ICU_admission → {reason}
      surgery → {procedure_name, urgency: "择期"|"急诊"}
      discharge → {discharge_diagnosis, discharge_medications:[], discharge_outcome: "好转"|"治愈"|"未愈"|"死亡", follow_up_plan}
  }]

规则：clinical_rationale 逐字引用原文；药物分类用7类字典；不推断因果；无信息填 null
```

## 维度 4 — 动态严重度

**输入文档**：病程记录、出院小结、肺功能报告

```
从以下病程记录、出院小结和肺功能报告中提取疾病严重度评估的时间序列。仅输出 JSON。按时间顺序排列。

字段：
- severity_assessments: [{
    time_point: "admission"|"day_N"|"discharge",
    date_offset_days: 整数（入院日=day 0），
    gold_stage: "I"|"II"|"III"|"IV"|null,
    gold_evidence: "explicit"|"inferred_from_fev1"|null,
    cat_score: 0-40|null,
    mmrc_score: 0-4|null,
    barthel_index: 0-100|null,
    exacerbation_severity: "轻度"|"中度"|"重度"|null,
    respiratory_failure: true|false|null,
    complications: ["名称"]|[],
    hospitalization_in_past_year: 整数|null
  }]

GOLD 分期【Level 1 — 显式】匹配："GOLD X" / "GOLD X级" / "COPD X级" / "慢阻肺 X级" / "极重度"→IV / "重度"→III（X=I-IV或1-4）
【Level 2 — FEV₁ 推算】≥80→I, 50-79→II, 30-49→III, <30→IV。两者均无→null。
CAT：匹配 "CAT"|"CAT评分" 后跟数字(0-40)
mMRC：匹配 "mMRC"|"MRC" 后跟数字(0-4)，COPD 上下文中
Barthel："Barthel"|"巴氏指数" 后跟数字
加重严重度：文本匹配 / 未分级时 ICU→重度、住院→中度
呼吸衰竭：文本匹配 / PaO₂<60+PaCO₂>50 → true
并发症：呼衰/心衰/肺心病/肺动脉高压/高血压/糖尿病/冠心病/感染/脓毒症
过去一年住院：从病史提取

规则：仅提取明确记录或合理推断的值；不编造；无信息填 null
```
