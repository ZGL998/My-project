## 附：仍需注意的 3 个口径点

1. **维度实体数两口径**：抽取期 **182**（history 12 / evidence 144 / treatment 9 / severity 17）→ 建模期 **123**（evidence 84 / severity 18）。论文正文用抽取期，README 已同时标注两口径。
2. **Task 3 R² 两口径**：per-seed 均值 **−0.013**（Table A.2）vs 图 3 pooled **0.057**（散点）。两值分别由 `_task3_true_cb_flat_compare.json` 与 `fig3_scatter_points.csv` 支撑。
3. **图 3 散点**：`fig3_scatter_points.csv` 为 10-seed pooled（R²=0.057）；`fig3_predicted_actual_trueCB.csv` 为 3-seed pooled（R²=0.043，供对照）。
